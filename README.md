# CoppeliaSim Joint Movements Demo

This is a simple robotics simulation project created in **CoppeliaSim**. 

##  About the Project
This scene demonstrates the basic movement of different types of robotic joints. It serves as a beginner-friendly example of how joints operate within the simulation. 

The scene includes examples of:
*   **Revolute Joints:** Rotating movements (like an elbow or wheel).
*   **Prismatic Joints:** Linear up-and-down or side-to-side movements (like a piston or elevator).

##  How to Run
1. Download and install [CoppeliaSim](https://www.coppeliarobotics.com/) (the educational version is free).
2. Download the `1st.ttt` file from this repository.
3. Open CoppeliaSim, go to **File → Open scene**, and select `1st.ttt`.
4. Press the **Play** button (▶) at the top of the CoppeliaSim window to watch the joints move.

##  File List
*   `1st.ttt` - The main CoppeliaSim scene file containing the robot joints.
